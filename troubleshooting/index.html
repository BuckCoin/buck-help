Troubleshooting

Describe an issue safely and find the next step.

Describe the issue safely

A useful description can include your operating system, the wallet version if known, what you expected, and the visible error message. Remove sensitive information before sharing text or screenshots.

Never share wallet secrets

Do not share seed phrases, private keys, passwords, or wallet backup files. Review screenshots carefully for private information.

Detailed fixes are being prepared

Verified fixes for specific BUCK Wallet errors are being prepared. This page does not yet recommend repair commands, data deletion, or recovery steps.

For project information, visit the official BUCK GitHub account. This Help Center does not currently provide a support submission form.
