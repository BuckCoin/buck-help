Synchronization

Understand the purpose of wallet synchronization.

What synchronization means

In a blockchain wallet, synchronization generally means bringing local blockchain information up to date with the network. The exact status indicators and controls depend on the wallet software.

BUCK Wallet guidance

Detailed synchronization guidance is being prepared. Verified status indicators, expected timings, and synchronization commands are not documented here yet.

If you need to describe a synchronization issue, review the troubleshooting guidance. Do not delete wallet data or run commands from an unverified source.
