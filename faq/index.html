Frequently asked questions

Find answers about this Help Center and its guidance.

Where are the installation instructions?

Detailed installation guidance is being prepared. See Getting started for the current documentation status.

Can I recover a wallet using this Help Center?

Verified recovery methods are not documented here yet. See Security & backup and avoid unverified recovery procedures.

Should I share a backup file to get help?

No. Never share wallet backup files, seed phrases, private keys, or passwords. This Help Center will never request them.

Where can I find synchronization commands?

Verified synchronization commands are not documented here yet. The Synchronization page explains the current scope.

How is documentation maintained?

Documentation is maintained in the BUCK Help Center repository. Technical procedures are added only after their functionality has been verified.
